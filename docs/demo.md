# Demonstrating IACA in under three minutes

Use a built workbench and a saved live Meta run. Reopening history makes no
additional API call. Keep fixtures visibly labelled.

| Time | Show | Explain |
| --- | --- | --- |
| 0:00–0:15 | Workbench and frozen contract | Generated code needs inspectable acceptance evidence. |
| 0:15–0:45 | Live Meta result and code difference | Wonder supplies only an expression. Say if reopening a recorded run. |
| 0:45–1:10 | Execution tests and symbolic proof | Independent oracle, actual proof branches, evidence-based acceptance. |
| 1:10–1:40 | Labelled mutation and scripted repair | Failed input, exact feedback and both attempts; do not attribute the mutation to Meta. |
| 1:40–2:05 | Insufficient-proof fixture | All tests pass, but a zero-step proof is incomplete: unresolved. |
| 2:05–2:30 | Export and scope | Reproducible records, resource limits and the attributed Refal foundation. |

The new contribution is the inspected generation/check/revision loop and
workbench. The Refal engine is a pre-existing foundation. State the supported
family honestly; reduction counts are suite-specific, not a general benchmark.

Rehearsals need no API calls. Retain evidence from a small live request, then
disable live calls for retakes. Keep credentials and internal development notes
out of the recording.
